# Swara-Recognizer---CS193
- An Indian Classical note recognizer
Project Goal:
- Recognize notes from the Indian Classical scale (S R G M P D N S) and recognize the raga (scale name) from note types.

MVP:
- Parse typed swara input (S R2 G3 M1 P D2 N3 S)
- Raga database: the 72 melakartas, generated by rule or loaded from a CSV
- Scoring: percentage of input notes that fit each raga
- Print the top 3 to 5 matches, ranked

Schedule: 
- Check arohanam/avarohanam order, not just the note set
- Add janya ragas to the database
- “Guess the raga” quiz mode
- Read note sequences from a text file
- Show a raga’s notes when you look it up by name

Tech Stack:
- Language: Java
- Build tool: Maven 
Libraries:
- TarsosDSP - pitch detection (if doing audio input)
- javax.sound.sampled - reading WAV audio (if doing audio input)
- Gson - reading ragas
- JUnit
- External tools: ffmpeg - converts MP3 to WAV
- Data storage: local ragas.json file, WAV files in a samples/ folder, console/CSV output
- Data sources: raga definitions entered by hand from public references (like the Melakarta chart), plus my own audio recordings
